# Звуки

Все файлы в `door/audio/` синтезированы для этой игры скриптом `door/tools/make_sfx.py`. Чужих записей нет.

Лицензия: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Можно использовать без указания автора.

| Файл | Что это |
| --- | --- |
| `ui/tap.ogg` | тихий стук кнопки |
| `ui/pen.ogg` | ручка по бумаге |
| `ui/page.ogg` | шелест страницы |
| `ui/good.ogg` | мягкий хороший исход |
| `ui/bad.ogg` | мягкий плохой исход |
| `ui/death.ogg` | конец серии |
| `ui/win.ogg` | победа |
| `scenes/door.ogg` | стук в дверь |
| `scenes/dog.ogg` | тихий лай |
| `scenes/basement.ogg` | капли и скрип |
| `scenes/food.ogg` | шуршание пакета |
| `scenes/letter.ogg` | бумага |
| `scenes/open.ogg` | скрип открытой двери |
| `scenes/stranger.ogg` | шаги |
| `scenes/radio.ogg` | шипение радио |
| `scenes/street.ogg` | ветер |
| `scenes/window.ogg` | стекло и ветер |
| `scenes/kid.ogg` | лёгкие шаги |
| `scenes/mirror.ogg` | тонкий звон |
| `scenes/cult.ogg` | далёкий гул |
| `scenes/soldier.ogg` | шаги и короткий сигнал |
| `scenes/horde.ogg` | далёкий тихий гул |
| `scenes/quiet.ogg` | сверчки |

Формат: моно OGG Vorbis, 22050 Гц, с коротким fade-in и fade-out. Пересобрать: `python3 door/tools/make_sfx.py`.
