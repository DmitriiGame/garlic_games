# Огурчик Чак

«Огурчик Чак: Сад Искушений» — статическая браузерная match-3 в духе roguelike: смахивайте камни, копите ману и творите чары в зачарованном огороде, где овощи флиртуют без стеснения. Игра помечена 18+: шутки пошлые, наготы и откровенных сцен нет. Страница на GitHub Pages: https://dmitriigame.github.io/garlic_games/

## Откроешь дверь?

Вторая игра, отдельно от Огурчика, в папке `door/` (Godot 4.7, GDScript). Корневые `index.html`, `game.js`, `style.css` и `assets/` не входят в её проект. После деплоя она открывается на https://dmitriigame.github.io/garlic_games/door/

Как открыть проект, дописать день и собрать Android — в [door/README.md](door/README.md). События лежат в `door/data/events.json`.

## Бросай и лови

Третья игра, тоже отдельно: папка `throw/` (Godot 4.7, GDScript). После деплоя она открывается на https://dmitriigame.github.io/garlic_games/throw/

Как играть, править баланс и собрать Android — в [throw/README.md](throw/README.md). Числа лежат в `throw/data/`.
