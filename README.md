# Огурчик Чак

«Огурчик Чак: Сад Искушений» — статическая браузерная match-3 в духе roguelike: смахивайте камни, копите ману и творите чары в зачарованном огороде, где овощи флиртуют без стеснения. Игра помечена 18+: шутки пошлые, наготы и откровенных сцен нет. Страница на GitHub Pages: https://dmitriigame.github.io/garlic_games/
